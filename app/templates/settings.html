Host SSH connections

An SSH key XCP Pulse uses to connect directly to a host, for any check that Xen Orchestra has no API route for — NIC statistics today, more may follow. Each host has its own key, saved separately below — never one key shared across hosts, so a compromised host's key cannot be used to reach any other. XCP-ng has no lesser dom0 account than root to create (dom0 user management is deprecated), so this key connects as root, the same account Xen Orchestra itself uses. Its actual privilege limit is a forced-command dispatcher script added to root's authorized_keys on that host — it allowlists a fixed set of read-only checks by name and refuses anything else, never a shell, regardless of what is sent to it. See Configuration in the user manual for the exact script and line to add.
