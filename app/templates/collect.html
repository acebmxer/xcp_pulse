Collect from a host

Downloads the host's log bundle — the same status report xen-bugtool produces, which is what Vates ask for — then, by default, makes a redacted copy using the rules switched on in Redaction. Expect roughly 870 MB of stored files and two minutes per host.

Adds about 770 MiB and a minute per host. The bundle already contains /var/log/audit.log and its rotated copies; this fetches the current trail uncompressed as a separate file. Most of it is the toolstack calling itself — storage scans and PBD updates — rather than a record of what people did.

Untick this to store the raw bundle only, faster and without a redacted copy taking up space alongside it. You can redact it afterwards from Jobs once you know which rules you want — useful if you plan to change a rule before sending anything.

A date range collects and redacts as normal, then extracts every category narrowed to that window into a second, smaller archive — the full bundle is still downloaded either way, this only shrinks what is kept afterwards.
